## STEP 3　关键检验：思考被计费但不计入 `out` 会怎样

### 3.1 残差 vs 思考强度代理

代理构造：`t` 是每条 API 响应的落账时点，故 `gap_before_i = t_i − t_{i−1}` ≈ 工具耗时 + 第 i 次调用的完整延迟（含思考）。用大输出点估计解码上限：`out>1500` 的 47 点 `out/gap` 分布 p50 = 26.3、p90 = **43.4 tok/s**。取 TPS_max = 43.4，构造 `excess = gap_before − out/TPS_max`。

| 代理 | n | 斜率 (¥/unit) | t | Pearson r | Spearman ρ |
|---|---:|---:|---:|---:|---:|
| `gap_before` (s) | 56 | +0.000023 | +1.59 | +0.211 | +0.236 |
| `excess time` (s) | 56 | +0.000023 | +1.60 | +0.213 | +0.217 |
| `gap_before/out` (s/tok) | 56 | +0.03851 | +1.37 | +0.184 | +0.206 |

**稳健性**（把会话边界的大 gap 剔掉后，符号翻转，说明代理不可靠）：

| 截断 | n | 斜率 | t | r |
|---|---:|---:|---:|---:|
| 全量 | 56 | +0.000023 | +1.59 | **+0.211** |
| gap<300s | 45 | +0.000084 | +1.16 | +0.174 |
| gap<120s | 29 | −0.000245 | −1.15 | **−0.217** |
| gap<60s | 10 | −0.001430 | −1.55 | **−0.480** |

按 gap 分位分组的残差均值（¥）：`-0.0111 / +0.0104 / +0.0179 / +0.0063`（Q1/Q2/Q3/Q4）。

> **读法**：Code 有机流量里**没有稳健的"慢调用 → 正残差"信号**；符号随窗口翻转。这正是"隐藏思考被计费"假说所**预测不到**的。

### 3.2 「低输出 + 长间隔」子样本

门槛 `out ≤ p25 = 1688 tok` 且 `gap ≥ p75 = 249.1 s` → n = 3（3 个点分别是 12:37:11、14:24:38、15:31:52，gap 均 ≈ 400–420s，属**用户思考/会话间隔**而非模型思考）。

|---|---:|---:|---:|
| 低输出+长间隔 | 3 | **+0.0136 ¥** | +0.0101 ¥ |
| 其余 | 53 | −0.0005 ¥ | −0.0103 ¥ |
| 差 | | +0.0141 ¥（Welch SE 0.0061，t = 2.31） | |

折算隐藏输出 = **+134 tok/call @ ¥105/M**。
**但**：0.0136 ¥ = **0.14 个量化格**。n=3、代理被会话间隔污染，这个"显著"不构成证据。

### 3.3 常数隐藏思考量 R̄ 的截距检验

模型强制过原点 ⇒ 若每次调用都被多计一个常数 ¥c，它会落进残差、并被"带截距"版本抓到：

| 参数 | 点估计 | HC1-SE | 95% CI |

RMSE 带截距 ¥0.0323 vs 过原点 ¥0.0325——**加一个截距几乎不改善拟合** ⇒ 没有常数偏置。

### 3.4 方差预算：隐藏思考量的最大可兼容量级

设 `RMSE² = σ_q² + σ_R²`（隐藏思考与回归量独立时）：

| 参照 RMSE | σ_R 上限 | 折算隐藏输出（@¥105/M） |
|---|---:|---:|
| 观测 0.0325（去保底 57 点） | ¥0.0150/call | **143 tok/call**（标准差） |
| 观测 0.0370（全 160 点） | ¥0.0231/call | 220 tok/call |
| **题目给定下限 ¥0.029** | **¥0.0028/call** | **26 tok/call** |

> 注意：去保底 57 点的 RMSE（¥0.0325）**已经略高于** σ_q（¥0.0289）。若严格要求 RMSE ≤ ¥0.029，则留给隐藏思考的方差预算只有 **26 tokens/call**——连一次像样的思考都装不下。

### 3.5 最重单点交叉核对

最大输出调用：`t=05:15:55, in=941, cache=170752, out=11194`，实扣 **¥1.200**。
过原点模型预测 **¥1.1973**，残差 **+0.0027 ¥**。
该点仍在 0.01% 网格上，半格余量 ¥0.05 ⇒ 可容纳隐藏输出 **≤ 502 tok**（相对 out = **k ≤ 4.5%**）。

### 3.6 【最关键】比例模型下 k 的置信上界

令 `R = k · out`（思考与可见输出成比例，这是唯一会**同时**污染 ¥105/M 与锚点的方式）：

```

HC1-SE(k) = 1.7810/105 = 0.0170
95% CI(k) = [−0.0370, +0.0295]      ⇒  k ≤ +3.0%（95%）
```

## 判定

### 1) 「1% ≡ ¥10 / 全池 ¥1,000」——**PASS（稳健）**

- 质疑前提被推翻：`out` 含思考（§5.4，R²=0.999，think 系数 0.97）。
- 即使完全不采信字段语义，纯靠计费残差反推：`k ≤ +3.0%`（95%）⇒ 锚点区间 **[¥963, ¥1,030]**。
- 三条独立路径互证：单点法 ¥996.8 / 聚合 OLS ¥992.8 / 比和法 ¥997.0。
- 报告未披露的口径事实：那个锚点单点里 6,618 tokens 中 **265 个是思考**，报告按同一口径计入——**没有偷换**。

### 2) 「Work 输出加价 2.6×」——**PASS（稳健）**

- Work Pout = ¥271.8/M（9 方程独立复现；报告 14 方程 ¥269.6/M），相对官方 ¥105/M = **2.59×**。
- 官方 ¥105/M 与 Work 实测价**同时**作用于"含思考的 output token"，**口径同构**，无系统性偏差。
- W1 独立佐证：65.2 s 的 step（含 29K 预填 + 41 输出）残差 +¥0.0029，思考若被额外计费会超出 6–9 倍余量而**未被观察到**。
- 报告的"输出占上午任务扣费 57%"是用 Work 卡价 × 可见 out 算的；因 `out` 已含思考，这个结构比**不需要修正**。
